# PapelariaGest

## Status do Projeto
Em desenvolvimento

## Tecnologias Aplicadas
* Java
* NetBeans IDE
* MySQL
* Git e GitHub

## Time de Desenvolvedores
* Celina Rezende Moraes Lima

## Objetivo do Software
Sistema desktop desenvolvido para automatizar e organizar o gerenciamento administrativo de uma papelaria, permitindo o controle eficiente de clientes, estoque de produtos e registro de vendas.

## Funcionalidades do Sistema
* Cadastro, consulta e gerenciamento de clientes;
* Cadastro e controle de produtos em estoque;
* Registro e acompanhamento de vendas;
* Integração e persistência de dados em banco de dados relacional MySQL.
